# astrbot_plugin_explain_slang

这是一个网络黑话/缩写解释器，调用「[能不能好好说话？](https://lab.magiconch.com/nbnhhsh/)」搜索你看不懂的缩写！

## 指令表
| 指令 | 说明 |
| --- | --- |
| /解释 arg1(string) | arg1是字符串类型，注意「解释」与arg1之间存在空格。 |
| /nbnhhsh arg1(string) | 上面指令的别名。 |

## 搜索结果
搜索结果将以如下的形式发送：
```txt
zssm: 这算什么 / 这是什么
```

## 配置
该插件无任何设置项，你可以去 AstrBot 的指令管理界面管理该指令。
